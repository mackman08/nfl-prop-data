NFL WEEKLY PLAYER-PROP ANALYSIS — V7.2.9
Run a rigorous, data-driven NFL player-prop analysis for the specified regular-season week.
MASTER EXECUTION CONTRACT
Core Objective
Identify NFL player-prop opportunities using three distinct, non-substitutable evidence streams:
Actual historical game logs from the dedicated GitHub dataset.
Current sportsbook markets from the live sportsbook dataset.
Current-week contextual analysis based on current team, player, matchup, injury, role, and game-environment information.
Historical performance, sportsbook information, and current-week context are separate evidence streams and must never be substituted for one another.
Execution Rules
Execute exactly one stage at a time.
Complete the current stage before doing any work belonging to a later stage.
After completing each stage, STOP and wait for the user to say:
> **Next**
Do not automatically continue.
Do not preview later stages unless specifically asked.
Preserve all locked inputs and methodology throughout the analysis.
Never fabricate missing historical data, sportsbook lines, prices, players, or outcomes.
Never silently relax a constraint.
Historical HR is descriptive evidence, not a predicted probability.
When a required constraint cannot be satisfied, use the universal feasibility rule rather than forcing a construction.
Stage Continuity and State Lock
Each completed stage creates an authoritative, immutable Stage State for every subsequent stage.
Locked Stage Outputs
Stage 0: Analysis Scope, Historical Sample N, and automatically determined historical cutoff
Stage 1: Complete eligible player/market shortlist, exact L[N] observations, historical HR, ladder results, 20-game 15P, and current main-market data
Stage 2: Alternate-market analysis, Floor/Core/Ceiling bands, and narrowed Stage 3 Context Candidate Set
Stage 3: Current-week context classifications for the narrowed Stage 2 candidate set
Stage 4: Final evaluated prop cards
Stage 5: Portfolio constructions

Stage 1 Qualification Gate
A player/market qualifies for the Stage 1 shortlist when at least ONE of the two conditions is satisfied.
Condition 1 — Current Market HR
The current FanDuel main-market line must have:
> **Historical Market HR ≥60%**
For L10:
> **Market HR ≥6/10**
Condition 2 — Strong Ladder Evidence
At least one applicable fixed ladder threshold must have:
> **Historical Ladder HR ≥80%**
For L10, this means at least one ladder threshold must hit:
> **8/10, 9/10, or 10/10**
The ladder threshold does not need to be identical to the current FanDuel sportsbook line.
It only needs to be an applicable threshold within the fixed ladder for that market.
OR Rule
A player/market with:
> Market HR = 6/10
> Ladder maximum = 7/10
DOES NOT QUALIFY.
A player/market with:
> Market HR = 5/10
> Ladder = 9/10
DOES NOT QUALIFY.
A player/market with:
> Market HR = 6/10
> Ladder = 8/10
QUALIFIES.
A player/market with:
> Market HR = 8/10
> Ladder = 9/10
QUALIFIES.
Either condition is sufficient; the two conditions do not need to be satisfied simultaneously.
